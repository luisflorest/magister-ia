# Magíster IA autodidacta

Programa autodidacta de inteligencia artificial aplicada a banca, de nivel diplomado: 20 semanas, unas 5 horas por semana, con Claude y ChatGPT como tutores.

Versión 1.0 · 12 de noviembre de 2026 · Luis Alberto Flores

## Qué hay en esta carpeta

| Archivo | Para qué sirve | Dónde se usa |
| --- | --- | --- |
| `programa.md` | Malla de 20 semanas, metodología, rúbrica, proyecto final y herramientas | Se sube como archivo a los proyectos de Claude y ChatGPT |
| `bitacora.md` | Registro semanal de avance, notas, brechas y errores del tutor. Es el puente entre las dos herramientas | Se actualiza cada semana y se vuelve a subir a ambos proyectos |
| `tutor/instrucciones-claude.md` | Instrucciones del tutor para el proyecto de Claude | Se pegan en las instrucciones del proyecto |
| `tutor/instrucciones-chatgpt.md` | Las mismas instrucciones, ajustadas para ChatGPT | Se pegan en las instrucciones del proyecto |
| `tutor/prompt-evaluador.md` | Prompt del evaluador externo y rúbrica | En un chat nuevo, fuera de los proyectos |
| `tutor/prompts-de-uso.md` | Prompts cortos para cada momento de la semana | En cualquiera de los dos proyectos |
| `portafolio/` | Entregables de cada semana | Una carpeta por semana |

## Reparto entre herramientas

| Momento | Herramienta | Por qué |
| --- | --- | --- |
| Clases de agentes, automatización y Copilot Studio | Claude | Bloques más técnicos |
| Práctica guiada y dudas rápidas | ChatGPT | Es lo que más consume |
| Cierre semanal y bitácora | Claude | Un solo lugar consolida el avance |
| Corrección de entregables | La herramienta que no se usó esa semana | Es el evaluador separado que pide el programa |
| Práctica con Microsoft 365, Power Automate y Copilot Studio | Copilot corporativo | Solo en las semanas 4, 13, 15 y 16, con la licencia del banco |

## Reglas
