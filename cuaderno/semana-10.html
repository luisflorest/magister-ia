APIs, webhooks, JSON y Make

Una automatización conectada necesita un contrato de datos y una respuesta clara cuando ese contrato se rompe.

En esta lectura

API, contrato y JSON Webhook y eventos Escenarios de Make Esquema Caso ficticio Fuentes

API, contrato y JSON

Una API expone operaciones con entradas, salidas y reglas de autenticación. JSON representa objetos, listas, números, texto, valores lógicos y null. Un campo ausente y un valor null pueden significar cosas distintas para quien recibe la petición.

Webhook y eventos

Con polling, el flujo consulta periódicamente si hay novedades. Con un webhook, el origen envía una notificación cuando ocurre un evento. Diseña el flujo para validar el origen, recibir duplicados y distinguir entre confirmación de recepción y procesamiento completo.

Escenarios de Make

Make organiza escenarios con módulos conectados. Mapea campos entre módulos y revisa qué ocurre al fallar una llamada. Reintenta solo fallas transitorias cuando la operación tolere repeticiones. Un identificador del evento permite detectar duplicados.

Caso ficticio

Banca y gestión de iniciativas

Una ficha ficticia llega dos veces con el mismo identificador. El flujo confirma la recepción y mantiene una sola entrada. Si falta el estado, deja el evento para revisión.

Para recordar

El éxito se mide en el estado final esperado. Recibir una respuesta HTTP exitosa acredita únicamente lo que ese endpoint se compromete a confirmar.
