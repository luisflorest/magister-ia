API de Claude con Python y RAG

RAG combina búsqueda de evidencia con generación. Así puedes comprobar qué parte del resultado está respaldada por un documento.

En esta lectura

Llamadas a la API Recuperación y respuesta Evaluación por etapa Esquema Caso ficticio Fuentes

Llamadas a la API

Un programa Python puede enviar mensajes a la API y procesar su respuesta. Mantén la clave fuera del código y de los registros. Maneja fallas de red y límites de servicio de forma explícita. Registra modelo, versión del prompt y consumo para comparar ejecuciones.

Recuperación y respuesta

Primero prepara fragmentos con metadatos como título, sección y versión. Luego recupera candidatos según la consulta y entrega al modelo un contexto acotado. La salida cita sus fuentes y se abstiene si la evidencia es insuficiente o contradictoria.

Evaluación por etapa

Mide si la recuperación encontró el fragmento esperado entre sus primeros resultados. Después revisa si la respuesta usa el fragmento correctamente y distingue vigencias. Si falla la recuperación, ajustar el prompt de redacción rara vez resuelve el problema de origen.

Caso ficticio

Banca y gestión de iniciativas

Un prototipo trabaja con documentos públicos de la CMF. Ante una pregunta que alude a una versión anterior, identifica la versión de cada fragmento y evita mezclar condiciones de textos distintos.

Para recordar

Una respuesta verificable cita el fragmento y la versión aplicable. La revisión legal o de cumplimiento sigue el proceso institucional.
