Carpetas y conectores

Una carpeta aporta archivos con un alcance fácil de delimitar. Un conector habilita acceso a un servicio según permisos y configuración. Para un piloto, inventaría qué fuentes se habilitan y si la integración puede escribir o enviar información.

Claude Code y skills

Claude Code puede trabajar sobre archivos de un proyecto. Una skill se documenta en un archivo SKILL.md y puede incorporar referencias. Una descripción precisa ayuda a activarla en el momento correcto. El cuerpo define insumos, pasos, formato y condiciones para preguntar o abstenerse.

Auditoría

Revisa cuándo se activa, qué datos lee, qué herramientas requiere y cómo se comporta ante faltantes o instrucciones incrustadas. Usa ejemplos breves para delimitar resultados válidos y revisa su comportamiento al cambiar las instrucciones.

Caso ficticio

Banca y gestión de iniciativas

Una skill de apoyo a fichas ficticias extrae problema, segmento y beneficio esperado. Un beneficio sin evidencia se marca como hipótesis y queda pendiente de validación.

Para recordar

Una skill mantenible tiene alcance estrecho, entradas explícitas y condiciones de salida que se puedan comprobar.
