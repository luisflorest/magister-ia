# Portafolio

Una carpeta por semana (`semana-01`, `semana-02`, ...). Cada una guarda:

- El entregable.
- La evidencia de que funciona: capturas, exportación del flujo o un enlace a un video corto.
- La revisión de riesgos.
- La nota y las observaciones del evaluador externo.

Solo datos ficticios o públicos. Nada de información de clientes ni interna del banco.
